# Go web-crawler-cli

CLI-приложение на Go для асинхронного обхода списка сайтов в пределах их доменов и построения дерева найденных страниц

## Возможности

- Несколько стартовых URL, обход каждого — строго в пределах его домена.
- Извлечение `<title>` и ссылок с каждой найденной HTML-страницы.
- Не более 10 одновременных запросов (глобально на весь обход) — контролируемый параметр.
- Отдельный таймаут запроса и общий таймаут выполнения.
- Пропуск редиректов, не-HTML-ресурсов и недоступных страниц.
- Без повторных запросов к уже посещённым URL, без циклов.
- Graceful shutdown по Ctrl+C — сохраняет то, что успели обойти.
- Результат — JSON-файл, ошибки и статусы — отдельный лог-файл.

## Особенности реализации

- **Глубина считается с 0**: сам стартовый URL — глубина 0, `--depth N` означает обход вплоть до глубины N включительно (`--depth 0` — только сами стартовые страницы, без переходов по ссылкам)
- **Редиректы, не-HTML и недоступные страницы** в `result.json` не попадают — только реально полученные HTML-страницы. Причина и HTTP-статус каждого пропуска — в лог-файле
- **Сравнение доменов** — по хосту без учёта порта, регистронезависимо

## Сборка

Требуется Go 1.26+

```bash
go build -o web-crawler-cli ./cmd/web-crawler-cli
go install ./cmd/web-crawler-cli
```

## Запуск

```bash
web-crawler-cli \
--urls https://google.com,https://example.com \
--depth 3 \
--timeout 2m \
--request-timeout 10s \
--output result.json \
--log crawler.log
```

## Флаги

| Флаг                | По умолчанию      | Описание                                                    |
| ------------------- | ----------------- | ----------------------------------------------------------- |
| `--urls`            | — (обязателен)    | список стартовых URL через запятую                          |
| `--depth`           | `0`               | максимальная глубина обхода (0 — только стартовые страницы) |
| `--timeout`         | `1m`              | общий таймаут выполнения                                    |
| `--request-timeout` | `10s`             | таймаут одного запроса                                      |
| `--output`          | `out/result.json` | путь к .json файлу с результатом                            |
| `--log`             | `out/crawler.log` | путь к .log файлу                                           |

## Graceful Shutdown

`Ctrl+C` прерывает обход через `context.Context` — уже пройденная часть URL'ов всё равно сохраняется в `result.json`
